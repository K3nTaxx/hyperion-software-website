Concept

DataClone vous permet de programmer l'un des modes de sauvegarde les plus puissants et importants : la sauvegarde d'image disque. Avec ce mode de sauvegarde, vous pouvez créer une image du disque entier, et restaurer votre ordinateur ou serveur en quelques minutes, sans avoir à réinstaller le système d'exploitation et tous les programmes.

Cette sauvegarde peut être effectuée sur tous les systèmes d'exploitation à partir de Windows Vista (Windows 7, Windows 8, Windows 10, Server 2008, Server 2012, Server 2016, Server 2019). La restauration fonctionne même si le matériel est différent.

Clonage de disque et P2V

DataClone est un logiciel permettant également de cloner des disques durs et de dupliquer un système d'exploitation sur différentes machines. En fait, DataClone vous permet de créer des images disques sous forme de fichiers VHD et VHDX qui sont des copies exactes des disques, y compris la structure logique des partitions. Cela permet de restaurer immédiatement un système en tant que machine virtuelle Hyper-V et d'utiliser DataClone comme logiciel pour convertir des machines physiques en machines virtuelles.

Création d'un disque de récupération

DataClone vous permet de créer un disque de récupération, une clé USB, ou un fichier ISO à graver sur CD. En démarrant une machine avec DataClone, vous pouvez sélectionner une image disque de sauvegarde créée et la restaurer sur un nouveau disque dur. Un utilitaire de restauration simple et parfait, même sur un matériel différent.

Image disque et restauration sur un matériel nu

DataClone fourni une image disque dans le format standard utilisé par Windows, sous la forme de fichiers VHD ou VHDX. Ces fichiers peuvent être ouverts pour récupérer des fichiers individuels, monté comme un disque dur classique, ou utilisé pour restaurer l'ensemble du système après un crash. Pour faire une restauration du système, il vous suffit de démarrer en utilisant le disque d'installation de Windows, et de sélectionnez la restauration à partir d'une image sur un autre disque ou sur le réseau.
