DataClone 365 : vos données Microsoft 365 reviennent chez vous

Le cloud reste votre espace de travail. Vos données, elles, reviennent aussi chez vous.

Microsoft 365 est devenu indispensable au fonctionnement quotidien des entreprises. E-mails, fichiers, espaces collaboratifs, échanges Teams : une part toujours plus importante du travail de l’entreprise réside désormais dans le cloud.

Avec DataClone 365, Hyperion Software ajoute une deuxième dimension à cette organisation : une sauvegarde de vos données Microsoft 365 directement sur votre propre infrastructure.

Outlook, OneDrive, SharePoint et Teams sont sauvegardés automatiquement sur une appliance Hyperion, un serveur ou un stockage dédié situé dans vos locaux.

01

Quand le cloud devient inaccessible, vos données restent accessibles

Une panne de connexion, un tenant indisponible, un compte compromis ou un incident majeur sur une infrastructure cloud ne devrait pas empêcher une entreprise d’accéder à son patrimoine numérique.

DataClone 365 conserve localement les éléments sauvegardés afin qu’ils restent sous le contrôle de l’entreprise.

E-mails, documents et données sauvegardées peuvent être consultés localement, même lorsque l’accès à Microsoft 365 n’est momentanément plus disponible.

Le cloud peut s’arrêter.
Vos données sont disponibles.

02

DataClone 365 passe en Mode Stealth®

La destination de sauvegarde reste verrouillée en dehors des opérations de copie.

DataClone 365 intègre le Mode Stealth®, le procédé de protection développé par Hyperion Software.

Lorsqu’une sauvegarde démarre, DataClone ouvre temporairement l’accès nécessaire à son service, réalise la copie puis referme la destination.

Une approche conçue pour réduire fortement l’exposition des sauvegardes aux écritures non autorisées.

Votre sauvegarde passe en mode furtif.

03

Restaurer uniquement ce dont vous avez besoin

La sauvegarde n’a de valeur que si l’information peut être retrouvée rapidement.

DataClone 365 permet de naviguer dans les différents points de sauvegarde et de sélectionner précisément un utilisateur, un dossier, un fichier, un site ou un élément sauvegardé.

Selon le service concerné, les données peuvent être restaurées vers Microsoft 365 ou récupérées directement dans un dossier local.

La sauvegarde devient ainsi une ressource réellement exploitable, et pas simplement une copie stockée quelque part.

DataClone 365. Microsoft 365 dans le cloud. Vos données sous votre contrôle.
